# Highway-Hustle-Game

A 2D car game built as my second JavaScript project, to practice and better understand how to build interactive things with JavaScript.

**Goal:** dodge as many enemy cars as you can, score higher than every other player, and take the #1 spot on the scoreboard.

## Features

- Create an account and log in to access the game
- Choose between two cars from the game menu
- Control your car with the arrow keys
- Dodge enemy cars on the highway
- Compete for the top spot on the scoreboard

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Object-Oriented Programming (OOP)
